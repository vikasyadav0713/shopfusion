# ShopFusion

ShopFusion is a modern, fast, and scalable eCommerce platform built with Next.js.

## Highlights
- App Router architecture with server components
- Prisma + PostgreSQL data layer
- Clerk authentication
- Clean, responsive storefront UI

## Getting Started
1. Install dependencies: `npm install`
2. Run migrations and seed (if needed): `npx prisma migrate dev` and `npm run seed`
3. Start the dev server: `npm run dev`

## Scripts
- `npm run dev` - Start development server
- `npm run build` - Build production bundle
- `npm run start` - Start production server
- `npm run seed` - Seed the database
- `npm run download:images` - Download product images and update DB paths
